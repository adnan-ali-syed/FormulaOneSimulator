# Project Scope

## Datathon microproduct

**Grid Battle** is the first product slice of Formula One Simulator.

### User problem
Formula One fans have access to large amounts of race data, but most predictive content is passive and fixed. Fans cannot easily test the counterfactual questions they naturally debate: *What if these two drivers started together? Does the track change the matchup? How much does grid position matter?*

### V1 user story
As an F1 fan, I can select two drivers, a circuit, and starting-grid positions so that I can explore which driver the model favours and understand the main reasons.

### V1 output
- probability Driver A finishes ahead
- probability Driver B finishes ahead
- model favourite
- interpretable model influences
- driver/team comparison
- grid sensitivity analysis
- observed head-to-head context

### Explicitly out of scope for V1
- official forecasting claims
- betting use
- live telemetry
- weather-derived controls
- tyre strategy simulation
- safety-car simulation
- full 20-driver race Monte Carlo

These remain future product layers.
